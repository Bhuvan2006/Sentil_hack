How It Works

Data

Live Rain Data

Fetches real-time precipitation from Open-Meteo API — no API key needed. Hourly rain intensity powers the flood risk score.

Map

City Road Network

Downloads the full driveable street graph from OpenStreetMap using OSMnx. Graphs are cached locally for fast reload.

AI

Flood Risk Model

A Gradient Boosting classifier assigns each road segment a 0–4 flood risk class using elevation, road type, proximity to water, and rainfall intensity.

Routing

Dijkstra Algorithm

Routes avoid flooded roads using Dijkstra's algorithm on a graph where high-risk roads have exponentially heavier weights. Critical roads are fully blocked.

API

Flask REST API

Flask backend exposes endpoints for city loading, weather data, road network GeoJSON, and route computation — consumed by this Leaflet.js frontend.

Safety

Risk Alerts

Compares flood-aware route vs normal shortest path. Shows risk distribution across road segments and issues alerts for dangerous conditions.
