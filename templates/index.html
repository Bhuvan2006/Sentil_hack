How It Works

Live Rain Data

Open-Meteo API

Fetches real-time precipitation — no API key needed. Hourly rain intensity powers the flood risk score.

City Road Network

OpenStreetMap

Downloads the full driveable street graph using OSMnx. Graphs are cached locally for fast reload.

AI Flood Model

Gradient Boosting

A Gradient Boosting classifier assigns each road segment a 0-4 flood risk class using elevation, road type, proximity to water, and rainfall intensity.

Smart Routing

Dijkstra Algorithm

Routes via Dijkstra's algorithm on a weighted graph where flooded roads carry exponentially higher penalties. Critical roads are fully blocked.

Backend

REST API

Flask backend exposes endpoints for city loading, weather data, road network GeoJSON, and route computation — consumed by this Leaflet.js frontend.

Safety Alerts

Risk Alerts

Compares the flood-aware route vs normal shortest path. Shows risk distribution across road segments and issues alerts for dangerous conditions.
